# ENTITY — Prototype graphique

Prototype V1 du corps graphique d’ENTITY.

## Objectif actuel

Valider la murmuration de base avant d’ajouter les propriétés psychologiques et émotionnelles.

- 100 billes
- cohésion
- séparation
- alignement
- distance de confort
- micro-respiration
- réglages en direct via lil-gui

## Lancer le prototype

```bash
npm install
npm run dev
```
